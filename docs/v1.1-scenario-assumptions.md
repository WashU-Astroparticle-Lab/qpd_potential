## Axis discipline (applies to ALL three inputs) — CONVENTIONS.md §B

Every locked input is tagged **keV_nr on the unified phonon energy scale** (T ≡ E_nr = E_dep), for BOTH
nuclear-recoil (neutron elastic, CEvNS) and electron-recoil (γ Compton, β/EC) deposits.

**§B FORBIDDEN guard (verbatim intent):**
- **No keVee ↔ keVnr scale mixing.** A keVee-quoted number placed on the phonon axis lands ~5× low.
- **No Lindhard / ionization-quenching (QF) factor** applied on this phonon scale. Applying a
  QF ≈ 0.1–0.3 would mis-normalize dR/dE by ~1/QF ≈ 4–6×. QF is used ONLY to *un-quench* an imported
  keVee number into keV_nr, never to quench a number already on the phonon scale.

**Surface-vs-underground non-transferability guard (Pitfall 2):**
- The surface baseline uses the raw sea-level flux with **NO shielding factor**.
- Shielded / underground residuals — **NUCLEUS (~250 dru), CONUS, RELICS** — are **post-shield residuals,
  NOT the unshielded surface flux**. They are back-corrected cross-checks only (VALD-08, Phase 12). The
  surface baseline is set as an *upper* case relative to them. Importing any such residual as the surface
  baseline (guard **fp-underground-import**) is forbidden.

**REFERENCE-MODEL CHANGE (documented decision — USER DECISION 2026-07-22).** The plan originally specified
the **Gordon-2004 / JEDEC JESD89A differential coefficients** for the spectral shape. Those are
paywalled/registration-gated and were **unsourceable in-environment** — the first execution run correctly
**BLOCKED** rather than reconstruct them from memory (fabrication). The resolution replaces the *shape source*
with the **fully open-access PARMA/Sato-2015 model** (whose fitted coefficients ship in the open PARMA/EXPACS
distribution — the PLOS ONE paper gives the functional forms, Eqs (4)–(6), and states the evaluated parameters
live in EXPACS), while **retaining Gordon-2004 as the absolute-normalization benchmark** via the >10 MeV integral
anchor. Shape and scale are both *sourced*, not improvised; the ~9% native PARMA↔Gordon agreement makes the
anchor a small, physically-motivated adjustment rather than a free knob.

**Discretionary pick (accepted):** outdoor sea-level PARMA default anchored to Gordon >10 MeV, with the
downward building-shielding band. **Limitation (unvalidated):** the building-shielding band is a pure scalar;
real roof/wall moderation reshapes the spectrum (fast→thermal) and a scalar understates that spectral-shape
systematic — carried as a Phase-8/12 sensitivity, not a full treatment.
