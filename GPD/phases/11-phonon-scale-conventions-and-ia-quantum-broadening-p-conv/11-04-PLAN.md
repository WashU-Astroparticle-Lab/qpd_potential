<objective>
Apply the impulse-approximation Gaussian broadening to `dR/dE_R` **before** the response chain, and
prove it does the two things ROADMAP SC4 demands: conserves counts to `<=1e-3`, and vanishes in the
correct limit by reproducing the frozen v1.0 result above ~10 eV to `<1%`.

Purpose: this is where the largest new physics input of the milestone actually enters the pipeline.
It is also where it can most easily be got wrong — by renormalizing away the mass that falls off the
bottom of the axis, by applying the kernel downstream of the response chain, or by defeating the
Phase-10 domain guard.

Output: the convolution implemented and wired upstream of `fold.rebin_cevns_to_edep_grid`, a leakage
budget, the broadened CEvNS recoil spectrum, and a regression proof against v1.0.

**TDD plan: every assertion below is writable before the implementation. Write the tests first.**
</objective>

  <action>
Write every test below **before** any convolution code exists. Each one is decisive on its own.

1. **Zero-width identity.** `broaden_dRdT` with `sigma_E -> 0` returns the input **bit-identically**
   (`np.array_equal`).
2. **Switch-off bit-identity.** The full fold with the broadening switch OFF reproduces the existing
   v1.0 chain output bit-identically — the same fail-safe property Phase 10 required of the trigger
   curve at `P_trig == 1`.
3. **Conservation with leakage.** Input counts vs output counts **plus** mass below the axis floor
   **plus** mass at `E < 0`; residual `<= 1e-3`. Assert explicitly that the leakage in the bottom
   decade is **non-zero** — with a 35-46% fractional width at 100 meV, a zero leakage entry means the
   kernel was clipped or the result renormalized.
4. **Strict linearity (no renormalization).** Scaling the input by an arbitrary constant `c` scales
   every output bin **and** every leakage entry by exactly `c`. Any global post-convolution rescale
