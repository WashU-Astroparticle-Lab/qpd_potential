<objective>
Build the per-fission reactor antineutrino spectrum S_i(E_nu) for the four reactor isotopes across 0.1-10 MeV, stitching the data-anchored Huber-Mueller conversion spectrum (>2 MeV) to a model-based summation + 238U(n,gamma) extension (<1.8 MeV), seam-matched across 1.8-2.0 MeV so no discontinuity appears.

Purpose: This per-fission spectrum is the shape half of the Phase-2 CALC-01 flux (advances claim-cevns). Plan 02-02 then applies the absolute normalization, uncertainty band, and freezing. The decisive requirement is that the sub-1.8 MeV region is MODELED, not truncated — it feeds the flagship low-recoil CEvNS bins in Phase 3.

Output: assembly code (src/flux/), fetched coefficient/summation/n-capture data with provenance (data/flux/), a seam-continuity inspection figure, and a unit-test module.
</objective>
